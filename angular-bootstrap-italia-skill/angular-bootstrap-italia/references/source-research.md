# Source research procedure

When behavior is unclear:

1. identify the installed Bootstrap Italia version;
2. open the exact official documentation page;
3. inspect installed typings and public exports;
4. inspect official JavaScript source read-only;
5. inspect official SCSS read-only when layout depends on it;
6. compare findings with the installed package;
7. use only the public/documented result;
8. if uncertainty remains, stop and state it.

Do not turn an internal class, method, event, selector, or implementation detail into a wrapper contract. Documentation and installed package version take precedence over generic Bootstrap knowledge.
