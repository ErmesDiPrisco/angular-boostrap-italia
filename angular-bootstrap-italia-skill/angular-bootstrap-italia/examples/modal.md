# Modal wrapper

Source: https://italia.github.io/bootstrap-italia/docs/componenti/modale/

Verify the official Modale markup and public API for the installed version before coding. Angular should own open state, content, labels, IDs, and action outputs. The Bootstrap Italia modal behavior must remain responsible for documented backdrop, focus, keyboard, and dismissal behavior.

Test accessible labelling, focus entry and restoration, Escape behavior, repeated open/close cycles, route changes, conditional destruction, and cleanup. Do not build a second modal engine in Angular.
