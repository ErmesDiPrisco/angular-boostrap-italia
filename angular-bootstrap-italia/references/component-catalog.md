# Component catalog

Use the official index as the live catalog: https://italia.github.io/bootstrap-italia/

Bootstrap Italia documents component families including Accordion, Affix, Alert, Avatar, Badge, Buttons, Card, Callout, Carousel, Chips, Collapse, Cookiebar, Dimmer, Dropdown, Hero, Modale, Notifiche, Overlay, Paginazione, Popover, Progress Indicators, Rating, Sections, Steppers, Sticky, Tab, Timeline, Tooltip, Video Player, navigation components, and form components.

For each requested component record: official URL, wrapper category, whether JavaScript is required, one initialization strategy, public configuration, Angular responsibilities, accessibility contract, safe extension points, customization risk, known limits, and version-sensitive notes. Do not claim an option or event until it is verified against the component page and installed package.

The only markup example maintained in this skill is the Accordion contract in `references/components.md`; other components are covered by the verified example files and must be rechecked against their official pages before implementation.
