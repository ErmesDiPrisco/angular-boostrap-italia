# Bootstrap Italia component catalog

Baseline: Bootstrap Italia 2.18.3. Entries link to real official component pages; live pages can move ahead of the installed version. Use [source research](source-research.md) for each implementation. This is a maintained selection of important components, not an exhaustive copy of the manual. The [official index](https://italia.github.io/bootstrap-italia/) includes additional variants.

## Reading the catalog

Every row gives its category, JavaScript/initialization/API, Angular responsibilities, accessibility concerns, safe extension points and known risks. **Static** means no Bootstrap Italia instance for the stated variant. **Managed** means the wrapper must verify construction, activation, public events and teardown; there is no universal constructor/options/dispose signature. A composite page may use more than one plugin.

Risk is about customization: low for content/semantic binding, medium for document flow or visual state, high for an imperative engine, positioning, focus or asynchronous transitions. All entries are version-sensitive; a specifically noted limitation takes priority. Do not infer APIs for unlisted variants.

## Selection rule

Follow the shared [customization order](customization-policy.md) for every row. A public constructor name is not permission to assume any particular method. Inspect the selected page, typings and runtime export; preserve the documented DOM and use [testing](testing.md). If a requested behavior needs internals or cannot be verified, STOP before generating an implementation.
