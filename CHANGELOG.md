# Changelog

## 1.1.0 — 2026-09-18

- Flattened the distribution so the skill directory and project documents live at the GitHub repository root.
- Corrected installation commands to the real `ErmesDiPrisco/angular-boostrap-italia` repository and verified `skills` 1.7.0 commands.
- Replaced generic example descriptions with six complete Angular modules covering static, interactive, customizable, Carousel, Modal and CVA wrappers.
- Removed conflicting Accordion state bindings and corrected instance ownership, delegated interactions, browser-only imports and teardown guidance.
- Verified Bootstrap Italia 2.18.3 Carousel configuration through `data-splide`, including responsive two-item layouts; prohibited private Splide access and CSS-only count hacks.
- Expanded the component catalog, Angular patterns, accessibility, forms, source research, customization order and mandatory STOP response.
- Added MIT license text, contribution guidance, audit evidence and isolated Markdown/Angular/browser validation tooling.

The audited example baseline is Angular 20.3.0, TypeScript 5.9.2 and Bootstrap Italia 2.18.3. This release does not require applications to upgrade dependencies.
